# Ma_Vie

**Ma Vie — le guide de mes journées**

Principe directeur : **« Est-ce que cette information sera utile pour moi ? »**

## v0.1 — prototype d'interface

- une seule interface responsive, pensée dès le départ pour Galaxy Z Fold plié et déplié ;
- « Maintenant » : rendez-vous restant aujourd'hui, avec heure et lieu ;
- « Demain » : aperçu volontairement moins détaillé ;
- avertissement de recharge anticipé ;
- « Pour moi » : exemples glycémie, voiture, météo et maison ;
- « À savoir » : premières suggestions du Guide (marché, transports) ;
- état « Plus de rendez-vous prévu aujourd'hui » ;
- état « Demain, aucun rendez-vous n'est prévu » avec Découverte et Djinn ;
- boutons de démonstration en bas pour tester ces états.

Toutes les données de cette version sont fictives. Les connexions aux vraies sources viendront après validation de l'ergonomie.
